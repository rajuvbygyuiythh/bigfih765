Dashboard direction · proposed

Operator-style dark workspace based on the Go/Wails and EVA project patterns: a fixed sidebar, clear Start/Stop, compact status strip, and separate functional pages. Source-based preference inference—not a confirmed final visual choice.

  1. Home: active site, current step, real blockers and Stop status.
  2. Sites: completion order, completed steps and evidence-backed locks.
  3. Messages: one TXT sequence with validation and local preview; provider use stays scope-gated.
  4. Sessions / Live Chat: isolated session state and consented/redacted diagnostic view, only where supported.
  5. Settings: non-secret controls and private server-configuration status.
  6. Logs / Tests: bounded reports; generated, accepted and peer-delivered are separate.
